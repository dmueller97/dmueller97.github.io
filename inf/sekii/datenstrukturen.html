    Arrays und Listen

    In vielen Programmen müssen mehrere zusammengehörige Informationen gespeichert und verarbeitet werden. Damit das übersichtlich und effizient möglich ist, organisiert man Daten in Datenstrukturen. Eine häufig verwendete Datenstruktur ist das Array. In diesem Kapitel lernst du Aufbau und Eigenschaften von Arrays kennen und setzt sie in Python als Listen um. Ganz unten findest du eine Python-Konsole mit Turtle — jeder Code auf dieser Seite lässt sich dort mit einem Klick laden und ausführen.

    Aufbau eines Arrays

    Ein Array ist eine geordnete Sammlung von Elementen, die unter einem einzigen Namen gespeichert sind. Jedem Element ist neben seinem Wert ein Index zugeordnet, der die genaue Position angibt. Der Index beginnt immer bei 0.

    daten[ ]

    Probiere auch negative Indizes wie −1 oder einen Index, den es nicht gibt.

    Eigenschaften. Ein Array hat eine feste Länge (hier 5), die Indizes laufen von 0 bis Länge − 1, und alle Elemente haben denselben Datentyp. Über den Index kann man auf jedes Element direkt zugreifen.

    Implementierung in Python

    Für die strikte Definition eines Arrays gibt es in Python das Modul NumPy. Die Standard-Datenstruktur für geordnete Aufzählungen ist aber die Liste. Sie unterscheidet sich von klassischen Arrays durch

    • eine variable Länge — Elemente können hinzugefügt und entfernt werden,
    • die Speicherung verschiedener Datentypen in derselben Liste.

    Wir betrachten deshalb nur Listen. Die vollständige Dokumentation findest du bei w3schools: Python Lists.

    BefehlVerwendung

    Iteration anhand des Index
    

    Möchte man mit allen Werten einer Liste arbeiten, muss man die Liste durchlaufen. Dafür gibt es zwei
Möglichkeiten: Iteration anhand des Index oder anhand des Wertes.
    

    

    So funktioniert es. len() liefert die Länge der Liste. Sie ist der Endwert
von range(), der exklusiv ist. Hat die Liste 5 Elemente, durchläuft i die Werte 0 bis 4 —
genau die Indizes. Mit newList2[i] erhält man den Wert an Stelle i.

    Iteration anhand des Wertes
    

    

    So funktioniert es. Die Position des Elements spielt hier keine Rolle: Die
